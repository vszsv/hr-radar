# Критерии квалификации лидов Ars Magna

## Целевой (квалифицированный) лид
Лид, соответствующий критериям, по которым измеряется статистика работы Менеджера по Новому Бизнесу.

## Необходимые критерии (без них НЕ берём в работу)
1. **Масштаб бизнеса:** Системообразующий (крупный) бизнес, либо средний бизнес со стоимостью проекта от 2.1 млн без НДС
2. **Есть задача/проблема**, которую надо решить

## Достаточные критерии (без них можем взять в зависимости от загрузки)
4. Имеется предполагаемый бюджет активации
5. Тендер закрытый (не на открытых площадках)*
6. Профильный, относительно основных направлений агентства (есть кейсы / близкие направления)
7. Есть сроки реализации
8. Контакт с ЛПР (лицом, принимающим решение)
9. Готовность клиента брифовать очно
10. Наличие иных активностей по нашему профилю у клиента
11. Отсутствие приоритетных поставщиков (результат тендера не предрешён)
12. Количество участников тендера не более 5

## Категории компаний
- **А+:** системообразующая (гос. статус)
- **А:** крупный бизнес (выручка > 2 млрд/год)
- **В:** средний бизнес (выручка 800 млн — 2 млрд/год)
- **С:** малый бизнес (выручка < 800 млн/год)

## Примечания
- * Допускается открытый тендер при глубокой коммуникации с командой или повторном проекте
- Если проект постоянный — чек = выручка за 1 мес
- Для ивентов — стоимость сметы по реализации мероприятия
- Размер компании можно проверить по ИНН на rusprofile.ru

## Что НЕ квалифицированный лид
- Спам / рассылки
- Подрядчики (предлагают услуги, а не заказывают)
- Малый бизнес без бюджета > 2.1 млн
- Нет конкретной задачи
- Нет контакта / клиент не выходит на связь
