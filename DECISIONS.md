## 2026-02-24: Account Director prompt calibration (5 iterations)
- **Что:** Откалибровали промпт account_director.txt по реальной выборке за 23-Feb
- **Почему:** Исходный промпт давал 6 target / 17 near — слишком много near, мало target
- **Результат:** 8 target / 8 near — 100% совпадение с ручной калибровкой Василия
- **Ключевые правила добавлены:**
  - Event Director/Team Lead в агентствах → target
  - IT-heavy и PR-heavy профили → near (не target)
  - Фриланс Event Directors с руководящим тайтлом → target
  - Event-менеджеры с зарплатой ≤80k → not_fit
  - Support/operations роли → near (не target)
- **Gemini 2.5 Flash vs GPT-4o:** Тестировали Gemini — слишком либеральный (18 target вместо 8), в 3 раза медленнее. Остались на GPT-4o.

## 2026-02-24: Account Manager + Project Manager calibration for event/BTL
- **Что:** Доработали промпты account_manager.txt и project_manager.txt по ручным комментариям Василия.
- **Почему:** ЛЛМ смешивал роли (AD/AM/PM), пропускал overqualified и мусорные профили.
- **Результат AM:** overqualified (AD-level), стажёры/нерелевантные профили отфильтрованы; выдача стала стабильнее для event+BTL.
- **Результат PM:** добавлен пост-фильтр в run_multi_radar.py для жёсткого отсечения role mismatch (няня/финансовый директор/AM/Head-TeamLead/студсоюзы); финальная выборка Event PM: target 14, near 9.
- **Техрешение:**
  - prompt-level правила в project_manager.txt
  - code-level safety net: `apply_project_manager_postfilter()` в run_multi_radar.py
- **Принцип:** если промпт нестабилен на спорных кейсах, фиксируем критичные правила пост-фильтром в коде.

## 2026-02-25: Кросс-ролевая дедупликация кандидатов
- **Что:** Если кандидат уже «точное совпадение» (target, confidence ≥ 75%) в роли с более высоким приоритетом (AD > AM > PM), он понижается до near_target в последующих ролях.
- **Почему:** Один и тот же кандидат мог появляться в «точных» для нескольких ролей, засоряя отчёт.
- **Как:** set `cross_role_exact_links` в `process_profile()`, проверка при мерже скоров.
- **Область:** Внутри одного профиля (Event или BTL). Между профилями дубли допустимы.

## 2026-02-25: Email-окно 24 часа вместо «сегодня по UTC»
- **Что:** IMAP-выборка переведена на rolling 24h (SINCE за 2 дня + фильтр по Date заголовку).
- **Почему:** Старая логика `SINCE today (UTC)` теряла вечерние письма предыдущего дня.

## 2026-03-06: Анализ видеоинтервью — /interview
- **Что:** Новая страница в веб-панели для анализа записей интервью с кандидатами
- **Почему:** Рекрутер проводит видеоинтервью, нужен структурированный AI-анализ
- **Решение:**
  - Пайплайн: скачивание видео (cloud.mail.ru / direct / upload) → ffmpeg → AssemblyAI (диаризация) → определение спикеров (Claude Sonnet) → анализ (Claude Opus/Sonnet 4.6)
  - Загрузка вакансии PDF + резюме PDF для контекста
  - Сохранение загрузок для повторного использования
  - PDF-отчёт через WeasyPrint
- **Анализ включает:** соответствие вакансии, психопрофиль с цитатами, анализ речи, психотипирование (акцентуация Личко/Леонгард, эннеаграмма, DISC, стиль в конфликте)
- **Стоимость:** Opus ~$0.45/анализ, Sonnet ~$0.22/анализ
- **Технические решения:**
  - AssemblyAI: REST API напрямую (SDK устарел), speech_models: ["universal-3-pro", "universal-2"] для русского
  - Cloud Mail.ru: dispatcher API для CDN-хоста (cloclo-weblink не резолвится из Финляндии)
  - Определение спикеров отдельным шагом ДО анализа (без bias от промпта вакансии)
